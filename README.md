# Сайт ООО «Оренбург АгроАльянс» (домен пока atg56.ru)

Статический сайт на Astro: русская версия в корне (`/`), английская — в `/en/`.
На выходе обычные HTML-файлы в `dist/`, их можно положить на любой хостинг.
Сервер нужен только для приёма заявок с формы (пример на PHP — в `server/`).

## Что нужно

- Node.js 20 или новее (проверено на 22).
- Для снимков экрана (`tools/shots.mjs`) — установленный Google Chrome.

## Запуск

```bash
npm install
npm run dev        # разработка: http://localhost:4321
npm run build      # проверка типов + сборка в dist/
npm run preview    # посмотреть сборку: http://localhost:4322
```

## Проверки перед выкладкой

```bash
npm run build                 # 0 ошибок astro check
npm run links                 # битые внутренние ссылки и якоря по dist/ (код 1, если есть)
node tools/shots.mjs --origin=http://localhost:4322 --w=1440,1280,768,390,360 --full / /kontakty/
```

`shots.mjs` пишет скрины в `tools/shots/` и сообщает о горизонтальной прокрутке (`HORIZONTAL OVERFLOW`).

## Форма заявки

Форма на «Контактах» отправляет POST с JSON на адрес из переменной `PUBLIC_FORM_ENDPOINT`.

- **Адрес не задан** (сейчас так) — форма ничего не изображает: собирает заявку текстом
  и предлагает отправить её в WhatsApp или скопировать. Ложного «отправлено» нет.
- **Адрес задан** — после ответа 200 форма показывает «Запрос отправлен»; при ошибке сервера
  оставляет заполненные поля и предлагает позвонить или написать в WhatsApp.

### Подключить приём в Telegram (хостинг с PHP)

1. Скопировать `server/send.php` в `public/api/send.php`.
2. Рядом, **прямо на сервере**, создать `api/send.config.php` по образцу
   `server/send.config.example.php`: токен бота от @BotFather и `chat_id` чата менеджеров.
   По желанию — `mail_to`, чтобы заявки дублировались на почту.
   Файл с токеном не публиковать и не класть в репозиторий.
3. Создать `.env` по образцу `.env.example`:
   ```
   PUBLIC_FORM_ENDPOINT=/api/send.php
   ```
4. `npm run build` и выложить `dist/`.
5. Отправить тестовую заявку и убедиться, что она пришла в Telegram.

Обработчик проверяет обязательные поля, отсекает ботов по скрытому полю `website`,
ограничивает частоту (раз в 20 с с одного IP) и отвечает 200 только если сообщение
действительно доставлено.

Без PHP подойдёт любой сервис, принимающий POST JSON (Formspree, Getform, свой сервер) —
достаточно указать его адрес в `PUBLIC_FORM_ENDPOINT`.

## Деплой

1. `npm run build`.
2. Залить **содержимое** `dist/` в корень сайта (`public_html`, `www` и т. п.).
3. Сайт собирается с `trailingSlash: 'always'`: страницы лежат как `/rynki/index.html`.
   Обычный Apache/Nginx отдаёт их без настроек. Для 404 указать `/404.html`
   (Apache: `ErrorDocument 404 /404.html` в `.htaccess`).
4. Домен задан в `astro.config.mjs` (`site: 'https://atg56.ru'`) — от него строятся canonical,
   hreflang, sitemap и OG-ссылки. Если домен другой — поменять там и пересобрать.

**Перед публикацией удалить** черновую лабораторию: `src/pages/lab.astro`, `src/lib/lab-map.ts`
и фильтр `/lab/` в `astro.config.mjs` и `tools/links.mjs`.

Яндекс.Метрика (счётчик 54298371) подключается только в продакшен-сборке.

## Где что менять

| Что | Где |
| --- | --- |
| Тексты RU и EN | `src/i18n/content.ts` — ключ добавлять в оба словаря |
| Адреса страниц | `src/i18n/routes.ts` |
| Телефон, адрес, мессенджеры, координаты, Метрика | `src/data/company.ts` |
| Культуры | `src/data/commodities.ts` |
| Политика конфиденциальности | `src/data/privacy.ts` |
| Цвета, шрифты, отступы | `src/styles/tokens.css` |
| Фото | исходники в `src/assets/photos/` → `npm run photos` (цветокор в `src/assets/graded/`) → `rm -rf node_modules/.astro` |
| OG-картинки | `npm run og` → `public/og-ru.jpg`, `public/og-en.jpg` |

Факты на сайте — из брифа заказчика (source/brief-aman-2026-11.md). Чего не хватает от заказчика —
в `CONTENT_GAPS.md`. Состояние работы — в `HANDOFF.md`.
